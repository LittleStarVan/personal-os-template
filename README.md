## 给 AI 的开场白（任何 AI 会话从这里开始）

先读 `00_系统/AI协作默认规范.md` 和 `00_系统/命名规范与使用说明.md`，之后所有操作严格遵守这两个文件——它们的优先级高于包括本文档在内的一切说明。

## 给人的三步上手

1. **第一次来**：读本页 + [[00_系统/命名规范与使用说明]]（10 分钟，知道东西放哪、命名怎么写）
2. **想从零搭一套**：读 [[00_系统/personal-os从0到1搭建指南]]，半天搭出骨架
3. **日常使用**：只需记住四条口令（下表）+ 随手记进 [[收件箱]]

## 日常节奏

- **每天**：随手记 → 收件箱（不分类）；睡前 10 分钟复盘（口令：今日复盘）
- **周日**：生成本周总结 + 整理我的收件箱 + 账本归档 + git 备份（如已配置），一次做完

## 四条口令（口令 = 卡名 + 任务，规则全在身份卡里）

| 你说 | AI 干什么 | 身份卡 |
| --- | --- | --- |
| 我要规划今天 / 规划明天 | 合并三来源建今日日记 + 播报今日三件要事 | 日规划教练卡 |
| 我完成了×× | 勾选 + 同步待办池 + 空位时播报补位候选 | 日规划教练卡 |
| 今日复盘 | 统计完成率、逐条处置未完成、写晚间复盘段 | 日规划教练卡 |
| 生成本周总结 ＋ 整理我的收件箱 | 生成周记 / 收件箱归档 + 待办池维护 | 日规划教练卡 ＋ 归档助手卡 |

口令全文见 [[00_系统/晨间规划工作流-模板与口令]]。

## 数据通路

**基础版（零门槛）：Obsidian（PC）+ AI（MCP）**——只在电脑上操作，系统就能完整跑起来。

进阶可选（随时后补）：

- 跨端同步：Obsidian ⇄ Fast Note Sync / FNS ⇄ 手机——**需要自己租服务器或阿里云**，没有服务器就先用 PC 版
- 冷备份：git → GitHub 私有仓库

> 同步管「多设备一致」，备份管「丢了能找回」——都是后补层，不是起步门槛。

## Obsidian 插件（强烈建议安装）

| 插件 | 用途 | 是否必须 |
| --- | --- | --- |
| Notebook Navigator | 日历侧栏：点任意一天直接定位/创建当天日记 | 强烈建议 |
| PDF++ | 在库内直接阅读、批注 PDF（论文/政策文件） | 强烈建议 |
| Fast Note Sync | 多设备实时同步（电脑 ⇄ 手机） | 可选——不配同步方案则不需要 |
