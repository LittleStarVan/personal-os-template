# 命名规范与使用说明

> 本文件是全系统的「交通规则」。改习惯改这里和身份卡，不动文件夹。

## 防重构三铁律

1. **一级目录只增不改**——10/20/30/40 骨架永固，新领域先走 YAML 属性，体量真大了才开新编号（50_、60_ 留了槽）
2. **新内容先进收件箱/待办池**——当场不做分类决策，每周由 AI 统一归
3. **规则与目录解耦**——习惯、偏好、约束全写在身份卡和本文件里，改规则不动一根文件夹

## 命名规范

- 文件夹：两位数字前缀 + 下划线 + 名词（`10_个人发展/`）
- 时间轴文件：日期开头（`2026-10-11.md`、`2026-W42.md`）
- 知识文件：名词命名，不堆日期（如 `视频脚本-skill.md`）
- 日记文件名带星期：`2026-10-11-星期日.md`（方便语音后肉眼定位）
- 日记按月度分子文件夹：`日记/2026-10/2026-10-11-星期日.md`；周记按年度分子文件夹：`周记/2026/2026-W42.md`——根目录永远只有「日记」「周记」两个文件夹，文件再多也不散落
- 星期用全写（星期一，不写周一）：与 Notebook Navigator 周期笔记语言包对齐，日历点选直接定位当天日记，不产生重复文件

## 笔记属性（强制）

- **所有笔记必须有 YAML 属性头**，新建时必填，不许裸奔
- **修改笔记内容时，先判断属性是否需要同步调整**（领域是否变了？状态是否从进行中转归档？日期是否该更新？）——内容变了属性没变，检索就会撒谎

## 笔记 YAML 属性头（两轴制的「属性轴」）

```yaml
---
领域: 工作            # 个人发展 | 工作 | 生活 | 财务
项目: 项目名            # 无项目可省略
类型: 知识            # 知识 | 决策 | 日志 | 模板
状态: 进行中          # 进行中 | 归档
日期: 2026-10-11
---
```

skill 笔记额外挂：`技能名 / 版本 / 触发词 / 元能力 / 最近验证`（见 模板/技能笔记模板.md）。

## 归属分工（高频疑问速查）

| 疑问 | 规则 |
| --- | --- |
| 读别人的（书/课程笔记） | 图书馆/ |
| 长自己的（原则、配置、试错） | 对应领域目录（如 40_财务/理财学习/） |
| 想法/洞察/世界观 | 认知库/（决定执行后立项进 创作输出/） |
| 工作交付 vs 私人关系 | 工作相关归 20_工作/，私人关系归 30_生活/，双链互连 |
| 复盘写在哪 | 就近原则：数据在哪个目录产生，复盘写在哪里的时间轴文件；跨域总览一律进周记 |

## 每日循环

随手记 → 收件箱.md → 睡前：归档收件箱 + 捞昨日未完成待办 + 明日计划以 todo-list 写入明早日记 → 完成待办时半自动载入补位

## 每周日

收件箱清零 + 待办池全检（含等待区滞留提醒）+ 周记生成 + **git commit & push（冷备份，每周一次即可，不随每次修改提交）**
